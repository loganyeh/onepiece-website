# Trading Card Game Web App (One Piece TCG UI Clone)

A responsive Trading Card Game web application inspired by the One Piece TCG website. The app allows users to browse and search trading cards using live API data.

## Features
- Browse and display trading card data from a live API  
- Search cards by name in real time  
- Responsive card-based UI layout  
- Clean and reusable component structure  

## Tech Stack
React, TypeScript, Tailwind CSS, REST API
